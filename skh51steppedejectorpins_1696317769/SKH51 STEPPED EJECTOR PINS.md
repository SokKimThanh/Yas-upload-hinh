### Dung Sai Chiều Dài

| Chiều Dài | Dung Sai L | Dung Sai LC |

| L ≤ 200 | +5 / 0 | +0.1 / 0 |

| LC > 500 | - | +0.5 / 0 |

### Dung Sai Đường Kính

| D (mm) | Dung Sai |
|--------|----------|
| 0 - 4 | 0 / -0.02 |
| 4 - 6 | 0 / -0.02 |
| 6 - 8 | 0 / -0.05 |

*Phạm vi đảm bảo độ chính xác đường kính trục (D) như EPDJ và EPDT ejector pins*

### Các Dung Sai Khác

- **Step Radius (R):** 
  - D ≤ 2 → R ≤ 0.3
  - D > 2 → R ≤ 0.5
- **H:** -0.30 / 0
- **P:** +0.02 / 0
- **N:** +5 / 0
- **T:** +0.01 / -0.02

## Gia Công Mặt Phẳng (Key Flat Cutting)

### 1. KC - Single Flat Cutting (Cắt 1 Mặt Phẳng)

- **Ký hiệu:** KC
- **Điều kiện:** P/2 ≤ KC < H/2
- **Dung sai:** 0 / -0.1
- **Đơn vị chỉ định:** Bước 0.05mm

### 2. WKC - Two Flats Cutting (Cắt 2 Mặt Phẳng)

- **Ký hiệu:** WKC
- **Điều kiện:** P/2 ≤ WKC < H/2
- **Dung sai:** 0 / -0.1

### 3. KAC/KBC - Varied Width Parallel Flats Cutting

- **Ký hiệu:** KAC, KBC
- **Điều kiện:** 
  - P/2 ≤ KAC < H/2
  - KBC = 0.1mm increments only
  - KAC < KBC < H/2
- **Dung sai:** 0 / -0.1
- **Đơn vị chỉ định:** 0.1mm

### 4. RKC - Two Flats (Right Angled) Cutting

- **Ký hiệu:** RKC
- **Điều kiện:** P/2 ≤ RKC < H/2
- **Dung sai:** 0 / -0.1

### 5. DKC - Three Flats Cutting (Cắt 3 Mặt Phẳng)

- **Ký hiệu:** DKC
- **Điều kiện:** P/2 ≤ DKC < H/2
- **Dung sai:** 0 / -0.1

### 6. SKC - Four Flats Cutting (Cắt 4 Mặt Phẳng)

- **Ký hiệu:** SKC
- **Điều kiện:** P/2 ≤ SKC < H/2
- **Dung sai:** 0 / -0.1

### 7. KGC - Two Flats (Angled) Cutting

- **Ký hiệu:** KGC
- **Điều kiện:** P/2 ≤ KGC < H/2
- **Góc (AG):** 
  - Bước tăng: 1°
  - Phạm vi: 0 ≤ AG < 360
  - Dung sai: ±0.5°
- **Dung sai KGC:** 0 / -0.1

### 8. KTC - Three Flats Cutting at 120° (Cắt 3 Mặt 120°)

- **Ký hiệu:** KTC
- **Điều kiện:** P/2 ≤ KTC < H/2
- **Góc:** 120° giữa các mặt
- **Dung sai:** 0 / -0.1

### 9. HC/TC - Custom Head/Thickness Cutting

- **HC (Head Custom):**
  - Điều kiện: P+1 ≤ HC < H, P ≥ 1.5
  - Đơn vị: 0.1mm increments
  - Dung sai: 0 / -0.3

- **TC (Thickness Custom):**
  - Điều kiện: T/2 ≤ TC < T, P ≥ 1.5
  - Đơn vị: 0.1mm increments
  - Dung sai: +0.1 / 0
  - **Lưu ý:** Dimension L becomes shorter by (T-TC)

## Ghi Chú Quan Trọng

1. **Về Độ Chính Xác:**
   - LC cho phép độ chính xác cao hơn với bước 0.01mm
   - L sử dụng cho các yêu cầu thông thường với bước 1mm

2. **Về Vật Liệu:**
   - SKH51 là thép gió tốc độ cao
   - Độ cứng 58~60 HRC đảm bảo độ bền cao

3. **Lựa Chọn Loại Đầu:**
   - ESH: Đầu JIS tiêu chuẩn
   - ESHT: Đầu 4mm, phù hợp cho không gian hạn chế

4. **Gia Công Đặc Biệt:**
   - Có thể yêu cầu gia công mặt phẳng (KC, WKC, DKC, SKC, v.v.)
   - Có thể gia công lỗ chốt (dowel hole) khi H ≥ 4mm
   - Các tùy chọn góc cắt linh hoạt với KGC
