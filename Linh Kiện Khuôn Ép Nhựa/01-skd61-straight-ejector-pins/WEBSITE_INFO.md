### Miêu tả ngắn
```
Chốt đẩy thẳng SKD61 thấm nitơ 900HV~, lõi 45~52HRC. Hai loại đầu: EPDJ (JIS head) và EPDT (4mm head). Dải đường kính 1.0-25mm, chiều dài 40-1000mm, bước LC 0.01mm, dung sai chặt. Hỗ trợ gia công KC/WKC/RKC/DKC/SKC, lỗ chốt NC.
```

### Nội dung chi tiết
```html
<h2>Chốt Đẩy Thẳng SKD61 EPDJ - EPDT</h2>
<p>Chốt đẩy thẳng SKD61 là linh kiện tiêu chuẩn cho khuôn ép nhựa và đúc áp lực, với bề mặt thấm nitơ đạt 900HV~, lõi 45~52HRC. Sản phẩm gồm hai lựa chọn đầu: EPDJ (JIS head) và EPDT (4mm head) giúp tối ưu không gian lắp đặt.</p>

<h3>Vật Liệu & Độ Cứng</h3>
<ul>
  <li>Vật liệu: SKD61 (thấm nitơ)</li>
  <li>Độ cứng bề mặt: ≥ 900HV</li>
  <li>Độ cứng lõi: 45~52HRC</li>
</ul>

<h3>Dải Kích Thước</h3>
<ul>
  <li>Đường kính thân P/PC: 1.0 - 25mm (bước 0.01mm cho LC)</li>
  <li>Chiều dài: 40 - 1000mm (L bước 1mm, LC bước 0.01mm)</li>
  <li>Đầu: EPDJ (JIS head) / EPDT (4mm head)</li>
</ul>

<h3>Dung Sai Tham Khảo</h3>
<ul>
  <li>P/PC 1~13mm: 0 / -0.01 đến 0 / -0.02</li>
  <li>P/PC 15~20mm: 0 / -0.03; đến 25mm: 0 / -0.05</li>
  <li>LC ≤ 200mm: 0 / +0.02; 200<LC≤500mm: 0 / +0.05; LC>500mm: 0 / +0.50</li>
  <li>Step radius: R ≤ 0.5 (P ≤ 2 → R ≤ 0.3)</li>
</ul>

<h3>Tùy Chọn Gia Công</h3>
<ul>
  <li>KC/WKC/KAC/KBC: cắt 1-2 mặt phẳng, bước 0.05-0.1mm</li>
  <li>RKC/DKC/SKC: cắt 2/3/4 mặt phẳng chống xoay</li>
  <li>KGC/KTC: cắt theo góc (0°..360° hoặc 120°)</li>
  <li>HC/TC: thay đổi đường kính đầu/độ dày đầu, bước 0.1mm</li>
  <li>NC: khoan lỗ chốt định vị (H ≥ 4)</li>
</ul>

<h3>Ví Dụ Đặt Hàng</h3>
<p><strong>EPDJ P5 L200</strong> hoặc <strong>EPDT P5 LC205.23 RKC2.54</strong></p>
```
