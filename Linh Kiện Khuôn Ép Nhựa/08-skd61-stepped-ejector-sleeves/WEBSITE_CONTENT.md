### Nội dung chi tiết

**Giới thiệu sản phẩm:**

Ống đẩy sản phẩm hai bậc SKD61 (ESVD/ESVDT) là linh kiện quan trọng trong hệ thống đẩy sản phẩm của khuôn ép nhựa. Với thiết kế hai bậc đường kính, sản phẩm cho phép đẩy nhả chi tiết ép một cách chính xác và hiệu quả, đặc biệt trong các ứng dụng đòi hỏi độ chính xác cao.

**Đặc điểm kỹ thuật nổi bật:**

- **Vật liệu cao cấp:** Thép SKD61 (tương đương AISI H13), chuyên dụng cho công nghiệp khuôn mẫu
- **Xử lý nhiệt tiên tiến:** Quy trình nitơ hóa (Nitrided) tạo lớp cứng bề mặt 900HV
- **Độ cứng lõi tối ưu:** 40 ± 3HRC đảm bảo độ bền và khả năng chịu lực tốt
- **Dung sai chính xác:** Đường kính ngoài đạt chuẩn H7, dung sai ±0.1mm
- **Phạm vi kích thước rộng:** Đường kính 5-20mm, chiều dài 50-500mm
- **Hai loại đầu:** JIS standard head và 4mm head phù hợp nhiều thiết kế khuôn

**Ứng dụng:**

- Khuôn ép nhựa chính xác cao

## 5. HƯỚNG DẪN ĐẶT HÀNG

### Cấu trúc mã đặt hàng

```
TYPE - P[giá trị] V[giá trị] D[giá trị] L hoặc LC[giá trị] N[giá trị] [Mã tùy chỉnh]
```

### Ví dụ đặt hàng chuẩn

**Ví dụ 1:**
```
ESVD - P5 V3.5 D6 L125 N50 KC3.5
```

**Giải thích:**
- **ESVD**: Loại ống đẩy hai bậc với đầu JIS
- **P5**: Đường kính trong = 5.0mm
- **V3.5**: Đường kính bậc = 3.5mm
- **D6**: Đường kính ngoài = 6.0mm
- **L125**: Chiều dài tổng = 125mm (bước 1mm)
- **N50**: Chiều dài phần bậc = 50mm
- **KC3.5**: Tùy chỉnh rãnh keyway sâu 3.5mm

**Ví dụ 2:**
```
ESVDT - P10 V8 D12 LC250.50 N100
```

**Giải thích:**
- **ESVDT**: Loại ống đẩy hai bậc với đầu 4mm
- **P10**: Đường kính trong = 10.0mm
- **V8**: Đường kính bậc = 8.0mm
- **D12**: Đường kính ngoài = 12.0mm
- **LC250.50**: Chiều dài chính xác = 250.50mm (bước 0.01mm)
- **N100**: Chiều dài phần bậc = 100mm
- **Không có tùy chỉnh đặc biệt**

### Bảng tùy chỉnh đặc biệt (Alterations)

| Mã Code | Tên tùy chỉnh | Dung sai | Điều kiện | Bước nhảy | Mô tả |
|---------|---------------|----------|-----------|-----------|--------|
| **KC** | Keyway (Rãnh then) | -0.1 / 0 | D/2 ≤ KC < H/2 | 0.1mm | Rãnh then tiêu chuẩn |
| **WKC** | Wide Keyway | 0 / -0.1 | D/2 ≤ WKC < H/2 | 0.1mm | Rãnh then rộng |
| **KAC-KBC** | Dual Keyway | KAC: -0.1 / 0<br>KBC: 0 / -0.1 | D/2 ≤ KAC < KBC < H/2 | 0.1mm | Hai rãnh then |
| **RKC** | Round Keyway | -0.1 / 0 | D/2 ≤ RKC < H/2 | 0.1mm | Rãnh then bo tròn |
| **DKC** | D-cut Keyway | 0 / -0.1 | D/2 ≤ DKC < H/2 | 0.1mm | Rãnh then chữ D |
| **KGC-AG** | Angular Keyway | KGC: 0 / -0.1<br>AG: ±0.5° | D/2 ≤ KGC < H/2<br>0° < AG < 360° | KGC: 0.1mm<br>AG: 1° | Rãnh then góc tùy chỉnh |
| **KTC** | 120° Triple Keyway | -0.1 / 0 | D/2 ≤ KTC < H/2 | 0.1mm | 3 rãnh then 120° |
| **TC** | Thinner Head | 0 / -0.02 | 2.0 ≤ TC < 4.0<br>4-TC ≤ Lmax-L | 0.1mm | Giảm chiều cao thân T, L không đổi |
| **HC** | Custom Head Height | 0 / -0.3 | D ≤ HC < H | 0.1mm | Tùy chỉnh chiều cao đầu H |

### Lưu ý đặt hàng

1. **Chọn loại đầu:** ESVD (JIS head) hoặc ESVDT (4mm head)
2. **Xác định kích thước cơ bản:** P, V, D theo bảng tiêu chuẩn
3. **Chọn chiều dài:**
   - L: Bước 1mm cho sản xuất tiêu chuẩn
   - LC: Bước 0.01mm cho độ chính xác cao (có phụ phí)
4. **Tính toán N:** Đảm bảo N ≥ L/3 (hoặc L/3 ≤ N ≤ 2/3L nếu L > 600)
5. **Thêm tùy chỉnh:** Nếu cần (KC, WKC, RKC, v.v.)
6. **Kiểm tra điều kiện:** Mỗi loại tùy chỉnh có điều kiện và giới hạn riêng
