# SKH51 Rectangular Ejector Pins (ERH / ERHT)

## Thông tin chung
- Vật liệu: Thép gió SKH51, độ cứng 58–60 HRC.
- Chủng loại: ERH (JIS head), ERHT (đầu 4 mm).
- Ứng dụng: chốt đẩy chữ nhật cho khuôn ép nhựa.
- Độ chính xác đường kính trục D: tương đương chốt EPDJ/EPDT.
  - D = 4 mm: dung sai 0 / -0.02 mm.
  - D = 6–8 mm: dung sai 0 / -0.05 mm.

## Kích thước chuẩn
- Bước kích thước P, W: 0.01 mm.
- Phạm vi tiết diện tham khảo (P × W):
  - P tối thiểu 0.50 mm, tối đa 3.50 mm.
  - W tối thiểu 0.80 mm, tối đa 11.80 mm (xem bảng kết hợp của catalogue).
- Chiều dài thân L / LC:
  - L: bước 1 mm; LC: bước 0.01 mm.
  - Các dải chiều dài khả dụng: 40–250 mm, 40–300 mm, 40–350 mm, 50–350 mm (tùy mã).
  - Điều kiện: 10 ≤ (L − N) ≤ 250.
- Chiều cao vai N: các cấp 1.5 / 2 / 2.5 / 3 / 3.5 / 4 / 4.5 / 5 / 5.5 / 6 / 6.5 / 7 / 8 / 8.5 / 10 / 10.5 / 12 mm.
- Bán kính góc R: R ≤ 0.5 mm (D ≤ 2 mm → R ≤ 0.3 mm).
- Dung sai chiều dài LC:
  - LC ≤ 200 mm: +0.05 / 0 mm.
  - LC > 200 mm: +0.10 / 0 mm.

## Tùy chọn gia công (Alterations Code)
- AKC / AWC / ARC / ADC: xoay đầu theo bội số 1°, 0–360°; khi kết hợp KSA/WSA chỉ dùng bước 90°.
- KGA / KGD: khoan lỗ ngang (góc 1°); phạm vi 0–360° (90° khi kết hợp KSA/WSA).
- WSA: dịch chuyển tâm chiều rộng W, bước 0.1 mm, điều kiện W/2 + 0.1 ≤ WSA ≤ W/2 − 0.1.
- TC / NC: khoan lỗ chốt định vị; TC bước 0.1 mm, NC bước 90°; giữ nguyên L và N.
- HCC: thay đổi chiều cao đầu H, bước 0.1 mm; điều kiện D + 1 ≤ HCC < H − 0.3, D ≥ 0.5 mm.

## Quy tắc đặt hàng
- Cú pháp: TYPE + P + W + L/LC + N + (mã alteration nếu có).
- Ví dụ:
  - ERH P2.8 W1 L165 N50 AKC 90
  - ERHT P2.5 W1 L125 N40

## Ghi chú
- P ≥ W + 1.0 mm.
