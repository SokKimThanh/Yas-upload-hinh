## Alteration Codes & Customizations

### Angular Position Codes

#### AKC - Angular Key Position Code
- **Range**: 0° ≤ AKC < 360°
- **Increment**: 1°
- **Positions**: 0°, 90°, 180°, 270°
- **Note**: When combined with KSA/WSA, 90° increments only
- **Offset**: D/2

#### AWC - Angular Width Position Code
- **Range**: 0° ≤ AWC < 360°
- **Increment**: 1°
- **Positions**: 0°, 90°, 180°, 270°
- **Note**: When combined with KSA/WSA, 90° increments only
- **Offset**: D/2

#### ARC - Angular Radius Position Code
- **Range**: 0° ≤ ARC < 360°
- **Increment**: 1°
- **Positions**: 0°, 90°, 180°, 270°
- **Note**: When combined with KSA/WSA, 90° increments only

#### ADC - Angular Dimension Code
- **Range**: 0° ≤ ADC < 360°
- **Increment**: 1°
- **Positions**: 0°, 90°, 180°, 270°
- **Note**: When combined with KSA/WSA, 90° increments only
- **Offset**: D/2

### Key Groove Codes

#### KGA - Key Groove Angle
- **Range**: 0° < KGA < 360°
- **Increment**: 1°
- **Positions**: 0°, 90°, 180°, 270°
- **Offset**: D/2

#### KGD - Key Groove Depth
- **Range**: 0° < KGD < 360°
- **Increment**: 1°
- **Positions**: 0°, 90°, 180°, 270°
- **Offset**: D/2

### Dimension Alteration Codes

#### HCC - Head Custom Cut
- **Increment**: 0.1mm
- **Range**: D+1 ≤ HCC < H - 0.3
- **Requirement**: D ≥ - 0.5
- **Tolerance**: 0 to -0.02

#### WSA - Width Side Alteration
- **Increment**: 0.1mm
- **Range**: W/2 + 0.1 ≤ WSA ≤ W/2 - 0.1
- **Tolerance**: 0 to -0.1

#### TC - Thickness Custom
- **Increment**: 0.1mm
- **Range**: T/2 ≤ TC < T
- **Constraint**: T - TC ≤ Lmax - L, D ≥ 1.5
- **Positions**: 0°, 90°, 180°, 270°

#### NC - Neck Custom (Dowel Hole Boring)
- **Increment**: 90°
- **Requirement**: Available when H ≥ 4
- **Note**: Dimensions L and N remain unchanged
- **Positions**: 0°, 90°, 180°, 270°

## Guaranteed Precision Range

Range of guaranteed shaft diameter precision (D) is equivalent to EPDJ and EPDT ejector pins.

## Order Example

**Format**: TYPE P D W L(LC) N (Alteration Codes)

**Example**:
```
ERN P3.5 D6 W1.2 L165 N50 VAK
```

**Breakdown**:
- TYPE: ERN
- P: 3.5mm
- D: 6mm
- W: 1.2mm
- L: 165mm
- N: 50mm
- Alteration: VAK

---

## Notes

1. All custom alterations must follow the specified increment values
2. When combining multiple alteration codes, ensure compatibility
3. Angular alterations with KSA/WSA are limited to 90° increments
4. Verify dimensional constraints before ordering
5. Contact manufacturer for special requirements outside standard specifications
