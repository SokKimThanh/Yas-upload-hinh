### 1. THÔNG TIN CƠ BẢN
#### Tên sản phẩm
- Tên tiếng Việt: Bộ chốt định vị côn pin-bushing lắp mặt phân khuôn (SKD11)
- Tên tiếng Anh: Tapered Pin Set / Pin-Bushing PL Installation Type (SKD11)
- Mã sản phẩm: TPVX
#### Miêu tả ngắn
VN: TPVX là bộ chốt định vị côn gồm pin và bushing lắp mặt phân khuôn, giúp tự định tâm và tăng độ chính xác lắp ráp khuôn.
EN: TPVX tapered pin set includes pin + bushing for PL installation, providing self-centering and precise positioning.
#### Nội dung chi tiết
VN: Bộ chốt TPVX dùng cho cụm định vị khuôn, gồm ① Pin và ② Bushing. Thiết kế côn tăng độ chính xác, có lỗ thoát (escape hole) ở đáy pin và lỗ ren tháo bushing. Vật liệu SKD11 58~62 HRC, nhiều góc côn và dải kích thước D 13–42 mm.
EN: TPVX is a tapered positioning pin set with pin + bushing. SKD11 (58~62 HRC), multiple taper angles and D size range 13–42 mm.
