# Yas-upload-hinh

## Giới thiệu
Project quản lý hình ảnh và tài liệu kỹ thuật cho các sản phẩm chốt đẩy (Ejector Pins) của Huan Sin Company Limited.

## Mục đích
- Lưu trữ và quản lý hình ảnh sản phẩm
- Quản lý thông số kỹ thuật và bản vẽ kỹ thuật
- Hỗ trợ upload và tổ chức tài liệu cho website

## Cấu trúc thư mục

### skh51straightejectorpin_1699427172/
Chứa thông số kỹ thuật cho sản phẩm **SKH51 STRAIGHT EJECTOR PINS** (Chốt đẩy thẳng SKH51)
- File TXT với thông số kỹ thuật chi tiết theo tiêu chuẩn JIS

### skd61steppedejectorpins_1701873044/
Chứa hình ảnh và tài liệu cho sản phẩm **SKD61 STEPPED EJECTOR PINS** (Chốt đẩy bậc SKD61)
- Hình ảnh sản phẩm gốc (.jpg)
- File thiết kế (.psd)
- Screenshots và hình ảnh thông số kỹ thuật
- Bảng thông số kỹ thuật

## Quy tắc đặt tên
Thư mục được đặt tên theo format: `[tên_sản_phẩm]_[timestamp]`

## Các loại file
- `.txt` - Thông số kỹ thuật văn bản
- `.jpg` - Hình ảnh sản phẩm và bảng thông số
- `.psd` - File thiết kế Photoshop
- `.png` - Screenshots và hình ảnh chỉnh sửa

## Sản phẩm hiện có
1. **SKH51 STRAIGHT EJECTOR PINS** - Chốt đẩy thẳng
2. **SKD61 STEPPED EJECTOR PINS** - Chốt đẩy bậc
